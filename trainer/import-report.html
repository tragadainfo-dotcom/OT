Проверка импорта

675 вопросов допущено к тренировке

В PDF найдено 679 записей: 225 в «1-2.pdf» и 454 в «3.pdf». В 261 импортированном вопросе несколько правильных вариантов. Дубликатов нет.

Ответы взяты только из отметок «(верно)» в блоке «Все ответы». Выбранные ответы из экзаменационного протокола не используются как ключ. Текст сохранён без смысловых изменений; нормализованы только пробелы и переносы строк, убрана служебная отметка правильности.

Для каждой записи проверены номер, порядок вариантов, число явно помеченных ответов и согласованность с явно верными ответами протокола. Исходные PDF сохранены побайтно, контрольные суммы есть в отчёте. У каждого вопроса есть ссылка на страницу оригинала.
