# Тренажёр экзаменационных вопросов

Раздел существующего статического сайта OT, без сборщика, сервера API и внешних ИИ-сервисов. Подготовлен на базе `main` (`280cb5e`), поскольку подключённая старая ветка содержала только три пособия и не имела актуальной навигации. Разработка выполнена в ветке `codex/exam-trainer`. Публикация в `main` разрешена пользователем после просмотра результата.

## Запуск и проверки

Из корня репозитория OT:

```sh
python3 -m http.server 8000 --bind 127.0.0.1
# В другом терминале:
node --test tests/trainer-engine.test.cjs
python3 tools/import_questions.py --check
python3 tests/trainer-browser.py
python3 tests/trainer-study.py
python3 tests/trainer-study-progress.py
python3 tests/trainer-mistakes.py
python3 tests/trainer-focus.py
python3 tests/trainer-search.py
python3 tests/trainer-search-focus-pwa.py
```

Откройте `/trainer/` на локальном сервере. Для импорта нужен Poppler (`pdftotext`), для браузерных проверок — Python Playwright и Chromium (`/usr/bin/chromium`; при другой установке укажите свой путь в тесте). Во время тренировки эти инструменты не нужны. При открытии HTML через `file://` браузер блокирует загрузку JSON; нужен HTTP-сервер. Никаких npm-зависимостей не добавлено.

## Импорт

- `sources/1-2.pdf`: 225 записей; в тренировке все 225.
- `sources/3.pdf`: 454 записи; в тренировке 450.
- Итого: 679 исходных, **675 подтверждённых**, **261** с несколькими правильными вариантами, **4** исключённых, дубликатов нет.
- Исключения в `3.pdf`: № 77 (ID 11792, стр. 18: нет варианта 5); № 153 (ID 6637, стр. 38: список начинается с 2); № 303 (ID 11789, стр. 71: список начинается с 0); № 417 (ID 14404, стр. 98: нет варианта 4). Пропуски не заполнялись, ключи не угадывались. Сырые фрагменты и причины в `import-report.json`; удобная сверка в `import-report.html`.
- Ключ извлечён исключительно из `(верно)` в «Все ответы», не из выбранных пользователем ответов протокола. Число отметок сверяется с «Всего ответов», также проверены явно верные ответы протокола.
- Сохранены исходные символы, включая латинские буквы в русских словах, числа, отрицания, единицы и ссылки на нормативные документы. Нормализованы только пробелы/переносы; служебный маркер правильности хранится как ID ответа.
- Используется `pdftotext -raw`: альтернативный PyMuPDF терял некоторые перекрывающиеся строки нормативных ссылок. Сканов и необходимых иллюстраций в вопросах не обнаружено; исходники сохранены неизменными, SHA-256 в отчёте. Каждый вопрос связан с номером, ID, темой и страницей PDF.
- Для обновления банка: замените/добавьте источники осознанно, измените ожидаемые количества в импортере, выполните `python3 tools/import_questions.py`, сверьте отчёт и запустите проверки. Стабильный ID `q-<ID из банка>` сохраняет связь с прогрессом. При изменении содержания под прежним ID потребуется отдельно решить миграцию; автоматического сброса нет.

## Повторение и прогресс

- «Изучение» открывает каталог трёх тем из PDF с группами по явно указанным НТД: можно выбрать один документ, всю тему либо весь банк. У каждой группы показаны пройденные и сложные вопросы. Все группы используют общий прогресс по стабильным ID. 11 вопросов без ссылки на документ находятся в группе «НТД в вопросе не указан»; принадлежность не угадывается. Выбранная группа сохраняется при перезагрузке и продолжении занятия. В изучении верный ответ исключает вопрос из следующих занятий до явного «Изучить заново» для группы или всего банка. В очереди остаются новые и ошибочные вопросы; пустая очередь показывает завершение. Отдельный признак `studyPassed` не равен полному освоению: повторения в других режимах продолжаются. Для старого прогресса прежние верные ответы учитываются автоматически. Перезапуск изучения сохраняет общие счётчики и результаты других групп/режимов. Порядок задаётся независимой настройкой (по умолчанию случайный); варианты по умолчанию перемешиваются при каждом новом показе.
- «Закрепление»: ошибки возвращаются по умолчанию через 7 других ответов, верные — через 18 с удвоением интервала. Для маленького банка интервал сокращается. Каждая четвёртая позиция отдаётся новому вопросу при его наличии, поэтому очередь ошибок не блокирует изучение всей базы.
- «Автоматизм»: та же очередь, дополнительно учитывается скорость, без таймера. Порог 6–45 секунд зависит от длины вопроса, всех вариантов и количества верных вариантов.
- Четыре этапа доступны сразу: знакомство, запоминание, смешанное закрепление (каждая третья позиция расширяет охват, успешные интервалы в 1,5 раза длиннее), автоматизм. Охват каждого этапа хранится отдельно. Этапы не зависят от календарных дат.
- «Освоен»: минимум 3 верных подряд, успешные ответы в разных занятиях и хотя бы один правильный повтор спустя 30 минут; в автоматизме нужны также 3 быстрых ответа подряд. Ошибка снимает освоение. Освоенные вопросы возвращаются по сроку или после достаточного числа других ответов.
- IndexedDB `ot-exam-trainer`, версия 1, одна атомарная запись состояния после каждого ответа. Сохраняются показы (`presentations`), попытки (`shows`), верные/ошибки, серии, время, сессии, уровень, ручная отметка, срок, настройки, очередь занятия и история отмены. Вторая вкладка блокируется Web Locks, чтобы избежать перезаписи.
- «Исправить последний ответ» откатывает статистику, срок повторения и охват этапа, позволяя ответить заново. Поддерживаются последние 30 ответов текущего занятия, в том числе после перезагрузки. Показ вопроса не отменяется: он действительно состоялся.
- Экспорт JSON содержит версию структуры и все записи, включая отсутствующие в текущем банке. Импорт проверяет структуру и согласованность счётчиков, требует подтверждения замены. Сброс тоже требует подтверждения. Прогресс не синхронизируется между устройствами; очистка данных браузера удалит его — используйте экспорт.

## Работа над ошибками

Отдельный режим с теми же тремя темами и всеми группами НТД. Каталог показывает число верно пройденных вопросов и остаток текущего круга. Пустые группы остаются видимыми, но недоступны для запуска. Можно выбрать документ, тему или все накопленные ошибки.

Новые записи используют `studyErrors`: счётчик увеличивается только при неправильном ответе в «Изучении» (включая первый этап программы). Ошибки в закреплении/автоматизме и ручная отметка сложности сами по себе не добавляют вопрос в этот режим. Верный ответ не удаляет историю ошибок, не очищает её и не возвращает вопрос в изучение. Перезапуск изучения также сохраняет историю ошибок. Отмена ответа восстанавливает счётчики из снимка; отменённая первая ошибка не добавляет вопрос в подборку.

Для старых записей без этого поля сохраняются ранее зарегистрированные ошибки (`errors`): прежняя версия не записывала режим, поэтому восстановить их точное происхождение невозможно. Это ограничение явно указано в каталоге. Новая ошибка в другом режиме для новой записи не считается ошибкой изучения. Импорт/экспорт сохраняют новые поля и принимают старые резервные копии.

В занятии каждый выбранный вопрос появляется один раз; размер ограничен количеством непройденных ошибок в группе и настройкой занятия. Следующие занятия прежде всего выбирают ошибки с наименьшим числом повторений (`mistakeReviews`). Поэтому даже при исходном порядке банк из 60 ошибок охватывается тремя занятиями по 20 вопросов, а не бесконечным повторением первой двадцатки. Верно отвеченные вопросы исключаются из следующих занятий до явного «Пройти заново». Отдельный флаг `mistakePassed` хранит завершение текущего круга; исходная история ошибок остаётся для нового круга. Неправильные и ещё не отвеченные вопросы продолжают появляться, а размер следующего занятия учитывает только остаток.

## Дополнительная проработка

Вопрос можно отложить кнопкой «На проработку» во время любого режима, в том числе после правильного ответа. Существующий ручной флаг `manual` используется для подборки: старые отметки «Сложный» также доступны в ней. Отдельная кнопка «Дополнительная проработка» на главной открывает тот же каталог трёх разделов и групп НТД, отфильтрованный по ручным отметкам.

В этом режиме `focusPassed` отмечает верный ответ текущего круга. Следующие занятия содержат только отмеченные вопросы без верного ответа в этом круге. После завершения доступно «Пройти заново» для выбранной группы/НТД или всей подборки. Перезапуск очищает только соответствующий флаг прохождения, сохраняя историю, статистику, ручные отметки и другие режимы. Снятие отметки удаляет вопрос из ручной подборки; повторная установка возвращает его в работу. Отмена ответа откатывает флаг прохождения вместе со статистикой. Импорт/экспорт сохраняют оба новых флага.

В старой версии не было отдельных флагов успешного завершения круга работы над ошибками или ручной проработки: старые записи без них начинают этот круг непройденными. При этом общие ответы, ошибки и счётчики повторений не сбрасываются.

## Поиск по вопросам

На главной тренажёра отдельный пункт «Поиск по вопросам». Введите от двух символов из формулировки: поиск работает по всем 675 подтверждённым вопросам, без регистрации ответа и изменения статистики. Сначала отображаются совпадения целой фразы, затем совпадения всех введённых фрагментов слов. Регистр, пунктуация и е/ё не учитываются; визуально похожие латинские буквы внутри русских слов PDF нормализуются только для поиска. Исходные тексты не меняются.

Результат содержит полную формулировку, тему, все явно правильные варианты в исходном порядке и ссылку на страницу исходного PDF. Неправильные варианты не выводятся. У каждого результата есть «На проработку» / «На проработке»: отметка сохраняется в ручной подборке и может быть снята. Счётчики попыток, верных ответов и ошибок при этом не меняются; отметка и текущие результаты изучения независимы. Поиск работает офлайн после сохранения оболочки/банка; PDF по-прежнему не кешируются. Вывод строится через textContent, поэтому поисковая строка и текст вопросов не интерпретируются как HTML.

## Навигация и офлайн

Сохранена общая панель: слева «Разделы», по центру «Домой», справа «Поиск». В общее меню и поиск добавлен тренажёр. Старые уроки не менялись.

В исходной `main` не было манифеста/Service Worker. Для всего сайта используется общий `manifest.webmanifest` с областью проекта (`/OT/` на GitHub Pages). Общая навигация добавляет одинаковые standalone-метаданные во все разделы, ссылки внутри сайта на iOS обрабатываются в том же окне. Старый URL `trainer/manifest.webmanifest` оставлен с прежним ID и начальной страницей, но область расширена до всего проекта для обновления уже установленных приложений. Service Worker по-прежнему ограничен `/trainer/` (также работает при размещении проекта в `/OT/trainer/`). Он сохраняет оболочку, банк вопросов и общую навигацию. Старые страницы и их кеши не перехватывает. Первый запуск требует сети и завершённой установки SW; PDF для сверки не кешируются. Установка PWA требует HTTPS либо localhost. Живые серверные процессы не входят в снимок окружения.

При будущем изменении оболочки увеличивайте имя кеша в `sw.js` и набор ресурсов. Новая версия SW ожидает закрытия старых вкладок, не перезагружая тренировку насильно. Данные IndexedDB при обновлении кеша не удаляются.

## Проверено

Модульные проверки банка, одно-/многовариантных ключей, интервалов, малого банка, освоения, скорости, импорта прогресса и смешанного третьего этапа. Браузерные проверки правильных/ошибочных ответов, отмены до/после перехода, перезагрузки, экспорта/импорта/сброса, перемешивания, отметок, четырёх этапов, автоматического перехода, поиска, офлайн-перезагрузки, двух вкладок, ширин 360/390/768/1280 и существующих пособий. Эти проверки выполнены до публикации; доступность рабочей версии проверяется отдельно после отправки в `main`.

Порядок вариантов: по умолчанию случайный во всех режимах. При обновлении прежняя настройка автоматически переключается на перемешивание один раз, без потери прогресса. Впоследствии пользователь может явно выбрать порядок PDF. Порядок при новом показе отличается от предыдущего показа того же вопроса; при выборе нескольких вариантов и отмене ответа кнопки не переставляются. Ключи проверки остаются стабильными ID.

Панель Safari (крестик, адрес, обновление) управляется iOS, а не CSS сайта. Проверены общий scope на корне и при размещении в /OT/, сохранение старого ID приложения, маршрутизация ссылок при navigator.standalone=true, офлайн и история. Нативный интерфейс реального iPhone в облачной среде не воспроизводился. Существующие базы IndexedDB и кеши других приложений не удаляются.
