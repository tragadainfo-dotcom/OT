# Поиск по пунктам приказа Минтруда № 223н

Источник — предоставленный пользователем DOCX, приказ от 20.04.2022, редакция от 25.04.2024, как указано в самом файле. Исходник сохранён побайтно в `sources/`, SHA-256 — в `document.json`.

Нижняя правая кнопка «Поиск» открывает этот раздел на всех страницах сайта. Поиск по разделам по-прежнему доступен через левую кнопку «Разделы». По умолчанию ищутся пункты Положения (приложение № 1); можно выбрать сам приказ, формы, классификаторы либо весь документ, чтобы различать повторяющиеся номера.

- 3 пункта приказа.
- 38 основных пунктов и 17 подпунктов Положения.
- 11 форм (приложение № 2).
- 3 раздела классификаторов (приложение № 3).

Запрос `20` возвращает пункт 20 и его подпункты, `20.4` — только 20.4 (не 20.14 и не 120.4). Принимаются `п. 20.4`, `пункт 20.4`, десятичная запятая. В формах номер означает номер формы; для классификаторов поиск также учитывает коды в таблицах. Доступен поиск словами, хотя интерфейс ориентирован на ввод пункта.

Импорт: `python3 tools/import_223n.py`, проверка: `python3 tools/import_223n.py --check`. Нужна только стандартная библиотека Python. Извлекаются абзацы, таблицы с вложенными ячейками, примечания и видимые текстовые ссылки. Весь видимый текст тела Word сверяется с извлечёнными блоками без учёта пробелов; номера основных пунктов, формы и ID проверяются отдельно. Текст не перефразируется. Полный документ доступен под результатами поиска. Таблицы прокручиваются горизонтально на телефоне.

В DOCX две иллюстрации: PNG отображается в полном тексте, исходный WMF сохранён в assets, а для просмотра этого фрагмента даётся ссылка на оригинальный DOCX. Нативные footnotes.xml/endnotes.xml содержат только пустые служебные разделители, текстовые примечания присутствуют в основном теле и сохранены.

Проверки при работающем HTTP-сервере из корня OT:

```sh
node --test tests/clause-search.test.cjs
python3 tools/import_223n.py --check
python3 tests/clause-browser.py
```

Отдельный Service Worker ограничен `/223n/` и кеширует оболочку и структурированный документ. Не удаляет кеши тренажёра и не меняет его IndexedDB. Оригинал DOCX не кешируется; для скачивания нужна сеть. При обновлении страницы/данных увеличивайте имя кеша в sw.js. Общий манифест сайта сохраняет единое окно приложения.
